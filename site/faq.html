FAQ

Questions and answers

Short answers about cost, privacy, browsers and the errors you might run into. If yours isn’t here, ask on GitHub.

Basics

What is TuffAgent?

A browser extension that adds an AI agent to the Chrome side panel or the Firefox sidebar. You describe a task in plain words, and it carries it out by reading pages, clicking, typing and working with your tabs, bookmarks, history and downloads.

How much does it cost?

The extension is free. To use it you need an OpenRouter account, and you pay OpenRouter for the models you use. Some models on OpenRouter are free, with rate limits.

The line under the composer shows what the current chat has cost so far. More on models and cost.

Which model should I use?

Start with the default, Claude Haiku 5.5, or one of the models in the picker’s Fast & capable section. Move to a larger model if long tasks start going wrong. How to choose a model.

Do I need to make an account?

Not with TuffAgent. The only account you need is with OpenRouter, for the API key.

Can I see the source code?

Yes, it’s on GitHub. There’s no build step, so the files in the repository are exactly what the browser loads.

Privacy and safety

What data leaves my browser?

Only while a task you started is running: your request, the page content the agent reads, any screenshots it takes, the titles and URLs of your tabs, and bookmark, history or download results if the task needs them. That goes to OpenRouter and the model provider you picked.

Nothing goes to a TuffAgent server, because there isn’t one. Read the privacy policy.

Will it buy things or send messages without asking?

It’s instructed to stop and ask before purchases, sending messages or emails, posting publicly, deleting data, or entering payment details or passwords, unless your request asked for exactly that.

That’s an instruction to the model rather than a hard block, so keep an eye on runs that involve your accounts or money.

How do I stop it?

Press Esc, or click the square stop button in the composer. Calls that hadn’t started yet are cancelled.

Why does it need so many permissions?

It’s a general-purpose agent, so it needs to read and act on whichever site you’re on, and use tabs, bookmarks, history and downloads when a task asks for them. It only uses them while carrying out a task you gave it. The privacy policy lists what each permission is for.

Does it work on sites where I’m signed in?

Yes. It acts in your browser, as you. That’s what makes it useful, and it’s also why you should only give it tasks you’d be comfortable doing yourself.

Browsers and setup

Which browsers does it work in?

Chrome 121 or later, and Firefox 128 or later. Tab grouping in Firefox needs version 138.

What doesn’t work in Firefox?

Three things depend on Chrome’s DevTools protocol: trusted input, the Google Docs and Canva site packs, and running JavaScript on pages whose security policy blocks it. Everything else works. More detail.

Why does Chrome say TuffAgent started debugging this browser?

That bar appears when Trusted input is on. It lets TuffAgent send real mouse and keyboard events, which some sites need. It’s attached only to the tab the agent is working in, and only during a task. Turn it off in Settings if you’d rather not see it.

How do I change the keyboard shortcut?

In Chrome, go to chrome://extensions/shortcuts. In Firefox, open about:addons, click the gear menu and choose Manage Extension Shortcuts.

Troubleshooting

It says my key was rejected.

OpenRouter didn’t accept the key; it may have been revoked or deleted. Click Update key and paste a new one.

It says I’m out of credits.

Your OpenRouter balance is too low for that model. Add credit on OpenRouter, or pick a free or cheaper model from the picker.

It says the model is unavailable.

Some models can’t take every request at every moment, or don’t support tool calling. Pick another model and try again.

The icons in the panel are missing.

The panel loads its icon font from beckettclarke.ca, so icons need an internet connection. Everything else works without them.

How do I report a bug?

Open an issue on GitHub. If you can, attach the exported log for that chat (History › download icon). Logs never include your API key, but they do include page content, so look it over before you share it.

Add TuffAgent to your browser.

Setup takes a couple of minutes: install the extension, paste an OpenRouter key, and open the sidebar with ⌘ ⇧ Y, or Ctrl Shift Y on Windows and Linux.
