Changelog

What’s new

Every release of TuffAgent, newest first. The full history is in the commit log on GitHub.

1.6.0Latest
November 4, 2026

Firefox

  • TuffAgent now runs in Firefox 128 and later, in the sidebar.
  • Without the DevTools protocol, page dialogs are answered from inside the page, actions wait on the network through webRequest, and pasting uses the page’s own paste command.

Panel

  • Theme setting: System, Light or Dark.
  • History search, with matches highlighted.
  • ↑ and ↓ in an empty composer step through earlier prompts.
  • Errors you can fix say how: Update key for a rejected key, Add credits and Change model for an empty balance, Change model for a model that can’t take the request.
  • Settings shows how many chats are saved and how much space they use, with Delete all, and lists shortcuts using the keys your browser actually has bound.
  • Onboarding lists the setup steps, can show or hide the key, and explains what data is sent.
  • Labels and dialog roles for screen readers.

On the page

  • The overlay matches the panel: an ink frame with a light hairline that reads on light and dark sites, a black cursor, and a label at the bottom with the current step.
  • Typed text never appears in that label.

Store

  • Store packages for Chrome and Firefox, a privacy policy, and store listings.
1.5.0
October 24, 2026

Look

  • A monochrome redesign of the side panel.
  • An ASCII field behind the panel that ripples when things happen (typing, sending, each step starting and finishing, errors) and pulses while the agent works.
  • An icon for every tool and most of their variants.
  • An activity strip in the composer showing whether the agent is waiting, thinking, writing, planning or acting, with a timer.
  • Copy buttons under messages, and the model picker moved into the composer.

Speed

  • Independent tool calls in one response (opening tabs, listing tabs, searching history, bookmarks and downloads) now run at the same time.

Site packs

  • New Canva pack.
1.4.0
October 23, 2026

Reading and aiming

  • Snapshots in reading order, with table rows, inline links, and what’s on screen kept first.
  • Clickable elements found by cursor, label and icon, including controls with no ARIA role.
  • Aiming by label, with near and nth when a label repeats.
  • Clicks find an uncovered spot on their target, and coordinate clicks snap to the nearest control.
  • Drag by label or by offset, with a check that something actually moved.
  • Typing into date, time and dropdown fields from plain values.
  • Every action reports what changed on the page.

Agent loop

  • Retries with backoff for rate limits, provider errors, and dropped or stalled streams.
  • Recovery when a request is too long for the model’s context window.
  • A nudge when a reply is cut off or checklist items are still open, and a warning when the model repeats itself.

Tools

  • Follows tabs opened by the page, answers JavaScript dialogs, and times out stuck page calls.
  • Waits for network requests an action started.
  • Repairs malformed tool arguments and understands tool names other agents use.
1.3.0

Site packs

  • New Google Docs pack: write, select, format, comment and read documents.
  • Formatted pasting of markdown and HTML into rich editors.
